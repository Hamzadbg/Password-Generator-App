# 🔐 Password Generator App

A modern and responsive **Password Generator App** built using React.js. This application allows users to generate random passwords with customizable length and character options.

Featuring a beautiful dark-purple gradient UI, light-yellow typography, and a simple, user-friendly interface.

## ✨ Features

- Generate random passwords instantly.
- Customize password length (10–20 characters).
- Include uppercase letters (A–Z).
- Include lowercase letters (a–z).
- Include numbers (0–9).
- Include special symbols.
- Copy generated passwords with one click.
- Input validation for password generation.
- Responsive and modern user interface.
- Attractive hover effects and button animations.

## 🖥️ Technologies Used

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/Hamzadbg/Password-Generator-App.git
```

**2. Navigate to the project folder**

```bash
cd Password-Generator-App
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm start
```

**5. Open your browser**

```text
http://localhost:3000
```

## 🚀 How to Use

1. Enter your desired password length (10–20).
2. Select the character types you want.
3. Click the **Generate Password** button.
4. Your password will be displayed.
5. Click **Copy** to copy your generated password.
